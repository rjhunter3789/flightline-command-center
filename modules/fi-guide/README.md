# FlightLine F&I Guide

Voice-first decision-support assistant for dealership F&I document completion, funding-package preparation, and jurisdiction-specific reminders.

## Purpose

The F&I Guide helps an F&I manager identify documents, disclosures, lender requirements, and deal-specific reminders before the customer leaves and before the funding package is submitted.

## Core principle

This system provides decision support only. It does not provide legal advice. All guidance must be sourced, jurisdiction-specific, version-controlled, effective-dated, auditable, and subject to dealership legal and compliance review.

## Planned structure

- `docs/` product requirements, workflow notes, and research
- `rules/` federal and general deal-document logic
- `lenders/` lender-specific funding requirements
- `jurisdictions/` state, county, and municipal requirements
- `prompts/` voice guidance and reminder language
- `audit/` source references, effective dates, and guidance history
- `src/` application code
